# U12b Events page: create and edit

**Status:** done · **Built in:** U: The Option A interface

## What was built

The Events page gets a New event button and lets each event be edited: a name, and an optional date of the same precision as a roll's date shot (a year, then month and day). Events are listed newest first, by date, with their dates shown ("Iceland 2026 · Sep 2026") and undated events last; the browse panel and the Event dropdown follow the same order. Renaming keeps the event's slug, so rolls stay in it. The roll forms keep Add new… as a shortcut that asks only for the name (D32).
