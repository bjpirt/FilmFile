# FF-156 Recover folders by their ID

**Status:** later · **Group:** Later

## What

A roll's, frame's or version's folder whose rename was cut short (a crash between renaming it and saving `roll.json`, D69) is found by the ID at the end of its name, and the rename finished: `roll.json`'s path put right, or the folder given its proper name. Run by the integrity check (FF-125) or on starting, and reported.

## Acceptance criteria

Written when the task is planned into a group.
