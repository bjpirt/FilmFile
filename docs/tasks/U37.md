# U37 Many frames in one save

**Status:** done · **Built in:** 5. Describing frames

## What was built

*(Was 1.3.5, "Frames". `UpdateFrame` and `UpdateFrameNumbers`: N3, N6.)* `UpdateFrames` gives every frame listed the same camera, film stock, lens or events of its own, or null to go back to the roll's, in one save of the roll with `If-Match`; nothing is saved if a detail isn't in the archive or a frame isn't in the roll. `PATCH /api/rolls/{rollId}/frames` takes `{ frameIds, camera, film, lens, events }` as well as `{ numbers }`.
