# U63 Events laid out like rolls

**Status:** done · **Built in:** Tidying the roll and events pages

## What was built

The Events page shows each event as the rolls page shows a roll: a card in a grid, with a strip of a few of its frames' thumbnails, its name and date, and how many rolls and photos it has ("3 rolls · 108 photos", counting rolls and frames in it through their frames too, U17), each card opening the event's page. Editing an event and New event keep working from the page, in the same card style as the rolls page's actions.
