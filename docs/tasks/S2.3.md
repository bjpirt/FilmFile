# S2.3 Web app shell

**Status:** done · **Built in:** 1. Foundations and the API slice

## What was built

Vite, React and TanStack Query in `apps/web`, calling the health endpoint through the typed client. The service serves the built UI; in development Vite proxies `/api` (D1). `pnpm dev` runs both against `.dev-archive/`; `pnpm build` builds the UI into `apps/web/dist`, which the backend serves, with `index.html` for any non-API path. UI tests use Testing Library with happy-dom. *(Was 0.3.4 and part of 1b.1.)*
