# U53 Breadcrumbs at title size

**Status:** done · **Built in:** 3. Rolls and the roll page

## What was built

The link back in a page's heading is the same size as the heading, in grey, with a "/" between them (a shared `breadcrumb` style): "All rolls / 2026-014" on a roll and on New roll, "Events / Iceland 2026" on an event, and "Roll 2026-014 / Frame 12" or "Iceland 2026 / Frame 12" in the frame view, where the roll number is no longer repeated after the heading.
