# U24 Delete a roll

**Status:** done · **Built in:** Deleting

## What was built

"Delete roll…" beside Edit details and Add scans swaps them, in place, for "Delete this roll and its 6 frames?" (or "Delete this roll?" when it has none) with Delete roll and Cancel. Deleting moves the roll's whole folder, roll.json and every frame's files, into `deleted/<time>-roll-<id>/` beside a `roll-deleted.json`, then opens the rolls page (D38). Sent with `If-Match`: the roll repository checks the version and hands the roll to the holding area under the roll's lock (`RollRepository.remove`), so nothing changes it in between. API: `DELETE /api/rolls/{rollId}` (204). The "Catalogue a roll" journey ends by deleting its roll. *(From 1.3.16, 1.4.3 and 1c.2.)*
