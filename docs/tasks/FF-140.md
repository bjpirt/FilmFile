# FF-140 No open port

**Status:** later · **Group:** Later · **Was:** U88

## What

The window reaches the service through a private `app://` protocol (`protocol.handle` handing requests to the service) instead of a port on `127.0.0.1`, so no web page can reach it at all. Browser access would then need the port turned on in Settings.
