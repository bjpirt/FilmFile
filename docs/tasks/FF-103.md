# FF-103 Choose the version shown

**Status:** to do · **Group:** 6. Versions and scans · **Was:** U62

## Why

A frame's first version, the lab's scan, isn't always the one I want to see once I have better.

## What

In the versions column (U61), each thumbnail has a star at its top left, filled on the version shown everywhere (`defaultVersion`, D15, D46).

## Acceptance criteria

- [ ] Each version in the versions column has a star at its top left; the one shown everywhere has it filled.
- [ ] Clicking another version's star makes that version the one shown on contact sheets, filmstrips, event pages and in the frame view, saved with `If-Match`.
- [ ] Clicking the first version's star goes back to the first.
- [ ] The star is named "Show this everywhere" for screen readers and on hover, and "Shown everywhere" when filled.
- [ ] Deleting the version shown (U28b) puts the first back.
- [ ] A save refused because the roll changed (409) leaves the star as it was and says so.

## Not in this task

- Showing the newest Final by itself (FF-135).

## Notes

- Uses the frame's existing `defaultVersion`.
- U28b's "⋯" menu was where "Show this everywhere" was first planned; a star replaces that.
