# FF-121 Publish a site to S3

**Status:** to do · **Group:** 5. Event sites · **Was:** U99

## Why

Putting an event's site on the web without other tools.

## What

"Publish" on an event's page uploads its site (FF-120) to an S3 bucket set in Settings; "Unpublish" removes it.

## Acceptance criteria

- [ ] Settings has the S3 bucket, its region and the AWS profile to use (from `~/.aws`), kept per computer (D52); no keys are kept by FilmFile.
- [ ] "Publish" uploads the event's site to `s3://<bucket>/<event>/` with the right content types, removes files no longer in it, and shows its address.
- [ ] "Unpublish" removes everything under the event's prefix, after asking.
- [ ] The event's page shows whether its site is published, and when.
- [ ] A failure (no access, no bucket) says what went wrong, without credentials or internals.

## Not in this task

- Setting up the bucket or CloudFront.
- Unlisted addresses (could come later).

## Notes

- Whether to use the AWS SDK or sign requests ourselves is to decide when this is built (a new dependency needs a reason).
- Publishing state goes in the roll's or event's `.state.json`-like file, per design section 5.
