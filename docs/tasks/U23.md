# U23 Delete a frame

**Status:** done · **Built in:** 3. Rolls and the roll page

## What was built

On the roll page, each frame shows a bin button when hovered or focused ("Delete frame 12"); clicking it covers the thumbnail, in place, with "Delete this frame?" and Delete and Cancel. Deleting saves the roll without the frame, with `If-Match`, then moves the frame's folder into `deleted/<time>-frame-<id>/` beside a `frame.json` saying what the frame was and which roll it came from; a roll changed elsewhere isn't overwritten. The holding area (`HoldingArea`) has filesystem and in-memory adapters and a contract suite. API: `DELETE /api/rolls/{rollId}/frames/{frameId}` (204, with the roll's new ETag). The "Catalogue a roll" journey deletes a frame. *(From 1.2.3, 1.3.16 and 1.4.3.)*
