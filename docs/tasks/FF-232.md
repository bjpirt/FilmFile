# FF-232 Back up when closing FilmFile

**Status:** to do · **Group:** 17. Sync and backup

## Why

Not having to remember to sync and hand back editing before closing the laptop.

## What

A "Back up when I close FilmFile" setting, in the desktop app only. When it's on, closing the app syncs, releases the lock and then quits, showing progress.

## Acceptance criteria

- [ ] In the desktop app, Settings → Sync has "Back up when I close FilmFile", off by default, kept on this computer. It isn't shown when FilmFile runs in a browser.
- [ ] With it on, and this computer holding the lock, closing the app (window close, Cmd+Q, or the menu) shows "Backing up before closing… 12 of 40". It then releases the lock and quits.
- [ ] If the sync fails (offline, say), it says "Couldn't back up: Couldn't reach Cloudflare." with "Quit anyway" (keeps the lock) and "Try again".
- [ ] With it on but without the lock, or with nothing changed, closing just releases the lock if held and quits.
- [ ] Shutting down or restarting the computer while it runs doesn't block the shutdown. The next opening shows "Not backed up since …" as usual.

## Notes

- The desktop app calls the service's sync API on close and waits. It imports nothing from the backend (D54).
- **Tests:** API (sync-and-release route), and a desktop journey (run last, `check.sh --desktop`) that closes with the setting on and finds the bucket synced and unlocked.
