# U2 Light table look

**Status:** done · **Built in:** 3. Rolls and the roll page

## What was built

The dark theme as tokens (colours, spacing, radii) in one stylesheet; Inter for text and IBM Plex Mono for roll and frame numbers, both served by the backend from installed packages (the CSP allows only the service's own origin, D21); the header with FilmFile and the Rolls link. Contrast checked to 4.5:1. Every existing screen restyled, with no change in behaviour: the journeys pass unchanged.
