# FF-227 Start a second computer from the bucket

**Status:** to do · **Group:** 17. Sync and backup

## Why

Getting the whole library onto another computer by pointing it at the bucket, not by copying folders by hand.

## What

On a computer whose FilmFile folder is empty, setting the bucket in Settings → Sync finds the library there and offers to download it. A folder that already has a library can connect only to that library's own bucket.

## Acceptance criteria

- [ ] With an empty FilmFile folder and a bucket that holds a library, the Sync section reads "This bucket has a library: 340 files, 12.4 GB, last synced by MacBook on 16 Nov 2026, 14:02." with "Download the library".
- [ ] "Download the library" downloads every file in the bucket's manifest to the same paths, with progress "Downloading 12 of 340" and "Cancel". When it's done, the library opens as on the other computer and the header reads "Synced just now".
- [ ] Each downloaded file is checked against the manifest's SHA-256 and size. A mismatch stops the download: "A file in the bucket isn't what the last sync recorded. Sync again on MacBook, then try again."
- [ ] A cancelled or failed download leaves the folder as it was, with nothing half-written in `Library/`. Trying again downloads only what's missing.
- [ ] With a folder that already has a library, a bucket holding a different library (another archive ID) is refused: "That bucket belongs to another FilmFile library."
- [ ] The desktop app's folder chooser accepts an empty folder as before (D64). The download is started from Settings, not the chooser.

## Not in this task

- Bringing an existing copy up to date (FF-228).

## Notes

- Downloads go to a temporary folder inside the FilmFile folder and are moved into `Library/` when all have arrived, so an interrupted download never leaves a half library.
- **Tests:** API (with the in-memory bucket seeded with a library), web (the offer and progress), and a journey: sync on one service, then start a second with an empty folder on the same in-memory bucket and download.
