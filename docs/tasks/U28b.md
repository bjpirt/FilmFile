# U28b Delete a version

**Status:** done · **Built in:** 6. Versions and scans

## What was built

In the versions column (U61), each thumbnail has a small "⋯" menu, shown on pointing or tabbing to it, with "Delete version…": "Delete this version?" covers the thumbnail with Delete and Cancel, and Delete moves its files into `deleted/` (the holding area's `holdVersion`, with `version.json` saying what it was), leaving the frame and its other versions, in one save with `If-Match`. Deleting the first asks "…edit-2.png will be shown instead." A frame's only version can't be deleted this way (the column isn't there for it; the API refuses): the frame is deleted instead. The menu is where "Show this everywhere" goes with FF-103. API: `DELETE /api/rolls/{rollId}/frames/{frameId}/versions/{versionId}`. *(From 1b.8 and 1.3.16.)*
