# U32 A roll's notes

**Status:** done · **Built in:** Frame view and describing frames

## What was built

A roll's description becomes its notes: "Notes" in place of "Description" on the new roll page, in Edit details and on the roll's page, and `notes` in the API and roll.json (schema 2; a schema 1 file's `description` is read as its notes). A roll's notes are its own: a frame doesn't inherit them, and its notes field stays its own (D40). Extends the "Describe a roll" journey.
