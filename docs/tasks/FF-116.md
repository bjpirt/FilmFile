# FF-116 Mark frames for export

**Status:** to do · **Group:** 5. Exports · **Was:** U94

## Why

Choosing the photos I want to share or print, as I go through rolls.

## What

A mark on a frame saying it's to be exported, set as FF-104's "to scan" mark is, and shown on its thumbnail.

## Acceptance criteria

- [ ] In the frame view, "Export" in the bar marks the frame for export; it then reads "Marked for export", and choosing it again takes the mark off.
- [ ] While bulk editing, Set ▸ "Mark for export" and Set ▸ "Don't export" mark or unmark every selected frame in one save.
- [ ] A marked frame shows an export icon in its thumbnail's row of icons, named "Marked for export".
- [ ] The roll page's heading says how many: "12 frames to export".
- [ ] A save refused because the roll changed (409) leaves the mark as it was and says so.

## Not in this task

- Making the exports (FF-117).

## Notes

- roll.json: the frame's `export: true`, only when set.
