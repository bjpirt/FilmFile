# U15 Frames' own details

**Status:** done · **Built in:** 5. Describing frames

## What was built

Frames gain their own camera, film stock, lens and events, each null unless set, in which case the roll's applies: kept in roll.json as the frame's `meta` and `events`, written only when set; set with `PATCH /api/rolls/{rollId}/frames/{frameId}` (checked against the archive's equipment and events; null goes back to the roll's). A frame's details now resolve archive → roll → frame, each saying where it came from. A frame may be in several events. The contact sheet marks a frame whose own details differ from its roll's with "Own" ("Its own camera and lens" to screen readers and on hover). Setting them in the browser comes with U16.
