# U64 Version kinds

**Status:** done · **Built in:** Multi-version frames

## What was built

Every version is a kind: **Scan** (ready to view, whatever its resolution: the lab's, or a positive of my own), **Raw scan** (the negative or slide as scanned, not yet processed) or **Final** (processed and edited) (D48). The "+" opens a menu, "Add scan…", "Add raw scan…" and "Add final…", each opening the file picker; scans added with "Add scans" on a roll are Scans, and versions already in a roll.json read as Scans. The versions column labels each version with its kind and its size in megapixels, and its "⋯" menu changes the kind ("Kind" ▸ Scan, Raw scan, Final), saved with `If-Match`. Kept in roll.json as the version's `kind`.
