# FF-145 Open a roll in darktable

**Status:** later · **Group:** 15. Integrate with darktable · **Was:** U79

## What

darktable gets its own folder in `Editors/` (FF-105), beside NegPy's. "Open in darktable" in a roll's Actions menu makes the roll's folder as FF-112 does and starts darktable on it; when darktable is already running, it says to add the folder with darktable's import module instead. Starting another program follows the security rules: one program, set in Settings, given a path the service made.
