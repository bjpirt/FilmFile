# FF-196 The service on Windows

**Status:** to do · **Group:** 10. Desktop app

## Why

FilmFile has never been tested on Windows. Its paths, renames and line endings need to work there before a Windows app is worth building.

## What

CI runs `pnpm verify` on Windows as well as on Linux and macOS, and whatever fails there is fixed in the code, not skipped.

## Acceptance criteria

- [ ] CI's `verify` job runs on `windows-latest` too, and passes.
- [ ] `.gitattributes` keeps text files with LF line endings on every checkout (`* text=auto eol=lf`), so Prettier's check passes on Windows.
- [ ] The safe-path helper rejects Windows forms too: `\` and `/` in a name, drive letters (`C:`), UNC paths, and names Windows reserves (`CON`, `NUL`, `COM1`), each with a test.
- [ ] Saving over a file, a site's swap into place (D92) and an export's rename work on Windows, where a rename over a file that's open or in use can fail. A failure is retried briefly, then reported, never half-done.
- [ ] Paths in the API and in `roll.json` (a version's `path`) use `/` on every platform.
- [ ] On Windows, caches are kept in `%LOCALAPPDATA%\filmfile` (not `~/.cache`), unless `FILMFILE_CACHE` says otherwise.
- [ ] The NegPy folder (FF-112) works where Windows doesn't allow links (no Developer Mode), by copying, as FF-112 notes.

## Not in this task

- The Windows app and its installer (FF-197).
- The browser journeys on Windows: the packaged app's journey covers the app there (FF-197).

## Notes

- Its size is unknown until CI runs on Windows. If what fails there is more than one review's worth, split it.
- Likely problems: `path.join` making `\` in stored paths, tests that compare paths as strings, `rename` giving `EPERM` or `EBUSY`, case-insensitive names, and the 260-character path limit for deep library paths.
- Already safe: folder labels keep only letters, digits and hyphens, and the ID suffix stops a roll called "CON" being a reserved name. `roll.json` already stores paths with `/`. _(From FF-139's notes.)_
- The cache folder is worked out in `apps/backend/src/composition/read-local-config.ts`.
- Test-first as usual: each fix starts as a failing test on the Windows runner.
