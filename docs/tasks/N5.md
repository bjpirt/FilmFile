# N5 Renumber preview

**Status:** done · **Built in:** N: Frame numbering

## What was built

A Renumber panel on the roll page that reads as a sentence: "[First|Last] scan is frame [N], counting [up|down]", so a tail-to-head roll is "last scan is frame 1, counting down". The contact sheet shows the proposed numbers in scan order, changed ones highlighted. Plain integers, going below zero if need be. Nothing is saved. UI only.
