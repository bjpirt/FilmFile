# FF-164 Find frames

**Status:** later · **Group:** 12. Exports

## Why

Finding frames across every roll by describing them is useful by itself, and what's found can be exported.

## What

A "Find frames" page: add rules (FF-177) and see the frames across every roll that match, live; and export what's found through the Export dialog (FF-165). Exports started from a roll's or an event's selected frames can also hold those frames by hand. *(Split: the rules, search, rule editor and grid are FF-177.)*

## Acceptance criteria

Written when the task is planned to be done.

- A "Find frames" link in the header opens the page with the rule editor, "24 frames match" and the grid, each frame opening in its roll.
- "Export these…" on the page opens the Export dialog (FF-165) with these rules as its frames ("24 frames match", and "Edit rules" which expands the rule editor and grid inside the dialog).
- A selection can also hold specific frames chosen by hand from the pages that start an export (the frame view's frame, a roll's or event's selected frames): shown as "12 frames chosen by hand" with "Review" and a way to take any out, never added from "Add a rule ▾"; a frame must be one of them to match, besides matching any other rules.

## Not in this task

- The rules, search, rule editor and grid (FF-177).
- Saving a selection as an export (FF-116).
