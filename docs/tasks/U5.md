# U5 Roll page layout

**Status:** done · **Built in:** U: The Option A interface

## What was built

The roll number heading with the frame count, Add scans in the toolbar opening the drop zone, the order choice and Renumber… beside the contact sheet, and the amber renumber bar. While renumbering, each changed frame shows its new number on an amber tag with the old number beside it, greyed out and struck through, and the bar says how many numbers will change.
