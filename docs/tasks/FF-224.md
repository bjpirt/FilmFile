# FF-224 A log file

**Status:** later · **Group:** 16. Internal improvements

## Why

In the packaged desktop app, the service's error output goes nowhere a person can find, so a request's 500 or a reported background failure (FF-203) can't be looked into.

## What

The service also writes what it reports (request errors and background failures) to a log file in the OS's place for logs (on a Mac, `~/Library/Logs/FilmFile/`), never in the archive, kept to a bounded size, with a way to find it from the app. _(Raised while refining FF-203.)_

## Acceptance criteria

Written when the task is planned to be done.
