# FF-179 A site's name is its title, and it has no intro

**Status:** to do · **Group:** 13. Sites

## Why

A simpler site with nothing to type twice and nothing unused.

## What

A site has one "Name", which is also the heading and the browser-tab title of its built page. "Page title" and "Intro" go from "How it looks", and `title` and `intro` go from a site's presentation. _(From feedback on the first sites, FF-119 and FF-120; took over FF-180.)_

## Acceptance criteria

- [ ] A site's page has "Name" (with "Rename", as now) and no "Page title" or "Intro" under "How it looks", which keeps "Group by" and "Captions".
- [ ] The built page's heading and `<title>` are the site's name exactly as typed, and it has no intro paragraph.
- [ ] Renaming a site makes it "Out of date" until it is built again; its address and file follow the new slug, and a folder already built under the old slug is left in `Sites/`, as FF-119 says.
- [ ] A site's `presentation` is `groupBy` and `captions` only, in its file, the API (`GET`, `POST`, `PATCH`), the OpenAPI spec and the generated types; a site with plain defaults still stores no `presentation`.
- [ ] The fake archive, the site's page tests and the build journey use the name as the title; `build-site.e2e.ts` finds the heading by the site's name.

## Not in this task

- A title different from the name, or any text under the heading: add them back if missed; the layout in FF-183 may bring a description on a card.
- Reading sites saved before this: they are not migrated (the same rule as FF-181, D103). A site saved with `title` or `intro` may fail to load if the file reader is strict, and is made again.

## Notes

- Changes `SitePresentation`, `defaultPresentation`, `SiteOptions` (`domain/sites/site-options.ts`), `renderSitePage` (the title now comes from the site's name, so `renderSite` is given it), the manifest (it records the options, so a changed name makes the site out of date) and `site-file.ts`.
- If the name isn't part of the options, the up-to-date check must compare it too, so a rename counts as a change.
- Do before FF-181, which changes the same selection and presentation code.
