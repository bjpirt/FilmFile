# S2.5 Roll page

**Status:** done · **Built in:** 1. Foundations and the API slice

## What was built

Drop lab scans onto a roll: for each file, create a frame and upload the scan as its version, with progress. Upload one file at a time: until H.9 adds locking, two requests changing the same roll at once can lose one of the changes. Show a contact sheet of thumbnails. Scans already in the roll (by SHA-256, hashed in the browser) and file names the service would refuse are skipped before a frame is created, so they don't leave empty frames. New frames are numbered in upload order, on from the roll's highest plain number (1 for an empty roll): a first guess until 1.3.9 sets numbering from anchors. A dropped folder contributes the JPEGs directly inside it. Pages are routed by a few lines of our own (`routing.tsx`) until there are enough to justify a router.
