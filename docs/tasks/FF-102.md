# FF-102 A roll's frames grouped by event

**Status:** to do · **Group:** 1. Multi-version frames, finished off · **Was:** U71

## Why

A roll shot across a trip and a day out reads better split by what was being photographed.

## What

When a roll's frames are in more than one event (the roll's, and frames' own, U17), its page shows them under a heading for each event.

## Acceptance criteria

- [ ] A roll whose frames are in two or more events shows a heading for each event, with its frames under it in frame order.
- [ ] The groups come in the order of their first frames, with frames in no event under "No event", last.
- [ ] Each heading links to its event's page.
- [ ] A roll whose frames are all in one event, or in none, looks as it does now, with no headings.
- [ ] While renumbering, every frame shows in scan order, without groups.
- [ ] Bulk edit works across the groups: Select all selects every frame, and shift-click selects a run across headings.

## Not in this task

- Grouping by anything else on the roll page.

## Notes

- Needs FF-101, so each frame has one event.
