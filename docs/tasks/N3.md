# N3 Edit one number

**Status:** done · **Built in:** 2. Frame numbering

## What was built

Click a frame's number to edit it in place; Enter saves, Esc cancels. Any text up to 9 characters; empty clears the number. API: `PATCH /api/rolls/{rollId}/frames/{frameId}` with the number, `If-Match` required (428 when missing, 409 when stale).
