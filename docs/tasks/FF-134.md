# FF-134 Add raw scans or finals to a roll's frames together

**Status:** later · **Group:** Later · **Was:** U66

## What

"Add scans" on a roll offers "Raw scans of these frames" and "Finals of these frames" as well as new frames, matching each file to its frame by the roll and frame number in its name (as FF-112 names them for NegPy), for other editors' files; NegPy's own exports come in by themselves (FF-113, FF-114), with a preview before anything is saved ("12A ← DSC04412.ARW; 3 didn't match").

Written when the task is planned into a group.
