# U28a Delete a frame from the frame view

**Status:** done · **Built in:** Frame view and describing frames

## What was built

A bin button in the frame view's bar, as on the roll page (U23), asking "Delete this frame?" in place; deleting it moves on to the next frame (or the previous, at the end, or back to where it was opened from when none is left), from a roll or an event. Extends the "Catalogue a roll" journey. *(From 1b.8.)*
