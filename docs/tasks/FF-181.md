# FF-181 Exclude a frame from a site with an ×

**Status:** to do · **Group:** 13. Sites

## Why

Taking a frame out of a site by looking at it, in one click, without a second mechanism to learn.

## What

Each frame the rules find has a small × in its top-right corner on a site's page. Clicking it greys the frame out and excludes it from the site; the greyed frame shows a ↺ in the same place to bring it back. "Always include", "Never include", "Always included" and the "Hidden" list go, and so does pinning: a selection is its rules and the frames excluded. _(From feedback on the first sites, FF-119 and FF-120.)_

## Acceptance criteria

- [ ] Every frame in the grid on a site's page has a button in its top-right corner, always visible, with the label "Exclude Roll 2026-053, frame 2" and an ×; it is a real button, reachable and used by keyboard, and works by touch.
- [ ] Clicking it greys the frame out and saves the site at once, quietly, as other changes do; the frame stays in the grid in its place, its button now a ↺ labelled "Include Roll 2026-053, frame 2 again", which brings it back.
- [ ] The count says "22 frames match, 2 excluded" ("1 frame matches"; with none excluded just "24 frames match"), counting only the frames that will be on the site.
- [ ] A frame that was excluded and is no longer found by the rules (the rules were changed) drops out of the grid and the count; it stays in the site's list, and shows again, greyed, if the rules find it again.
- [ ] An excluded frame is not in the built site, and the site's status says "Out of date: 1 removed" until it is built again; including it again makes it "Out of date: 1 added" (or "Up to date" if built in between).
- [ ] A hidden frame (D99) is still never found, excluded or not.
- [ ] The page has no "Always include", "Never include", "Always included" or "Hidden: 2" list; `pinned` is gone from a selection, the OpenAPI spec and the search.
- [ ] A selection is `{ rules, excluded }` in a site's file, in the API and in `POST /api/frames/search`; `excluded` is a list of frame references, kept in a stable order, and a site with nothing excluded writes `excluded: []` as before it wrote `hidden: []`.
- [ ] `POST /api/frames/search` returns the frames the rules find, each marked `excluded` when it is in the selection's list, in shot order, with the count of the others, so the page can grey them.
- [ ] A frame deleted or moved so its reference is gone is dropped from the list on the next save and never breaks the page.

## Not in this task

- Adding a frame the rules don't find: change the rules (there is no pinning, D103).
- Excluding on exports (FF-116). Excluding selected frames from the roll and event pages was FF-163, dropped: the × on the site's page does it.
- Hiding a frame everywhere: D99.
- Reading sites saved before this task: they are not migrated (see Notes).
