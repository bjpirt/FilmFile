# U56 One Set menu while selecting

**Status:** done · **Built in:** Tidying the roll and events pages

## What was built

The selection bar above the frames keeps its place, with "3 frames selected", Select all, Clear, a "Set" menu (Event…, Camera… and Lens…, each opening its choice in the bar, closed by Esc), Delete… and Done; the four "Set …" buttons go. The Actions menu is put away while selecting. Putting the bar in the Actions menu's place was tried and found too complex. The "Bulk edit" journey follows the new steps.
