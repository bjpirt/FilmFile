# FF-161 An Intel Mac build

**Status:** later · **Group:** 10. Desktop app

## What

The packaged Mac app also built for Intel Macs (`x64`), as its own `FilmFile` disk image beside the Apple silicon one, made and checked in CI.

## Acceptance criteria

Written when the task is planned into a group.

## Notes

- `apps/desktop/scripts/package.ts` is fixed to `darwin`/`arm64`; it needs an `arch` option, with the packager's `arch` and the DMG's name following it (`FilmFile-x64.dmg`).
- sharp's native files are the catch: pnpm installs only the host machine's (`@img/sharp-darwin-arm64`), and the script copies sharp's packages into the app by hand (`copyPackage`), so an x64 app built on an Apple silicon Mac would ship the wrong binary. Either build on an Intel runner, or install every platform's packages (`supportedArchitectures` in `pnpm-workspace.yaml`, then copy the target's `@img/sharp-darwin-x64` and its libvips package in).
- CI: a second `desktop-app` job (or a matrix over `arch`) on an Intel runner, running the packaged-app journey and uploading its DMG; or one universal app (`@electron/universal`), which needs sharp's two binaries kept apart (its `x64ArchFiles` option) and is the larger change.
- Unsigned builds show Gatekeeper warnings as the Apple silicon one does; signing is FF-137.
- Sizes: about half a day.
