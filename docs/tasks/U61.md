# U61 Versions in a column

**Status:** done · **Built in:** Multi-version frames

## What was built

In the frame view, when a frame has more than one version, a column of them runs up the left of the image: a small thumbnail of each, turned as it is, labelled with what it is (its file for now, its source once versions have one, U20), the one shown everywhere marked, and the "+" (U34) at its foot. Clicking one shows it in the frame view only, for a closer look; the filmstrip and contact sheets keep the first. The versions list goes from "About this frame". A frame with just its lab scan has no column, only the bar's "+".
