# U36 A frame's resolved details

**Status:** done · **Built in:** 5. Describing frames

## What was built

*(Was 1.3.3, "Resolved rolls". `UpdateRoll`: U8.)* `GET /api/rolls/{rollId}/frames/{frameId}/details` gives what a frame inherits, resolved by U35 from the archive and its roll: author, copyright, camera, film stock, lens and events, each with the layer and ID that set it (`GetFrameDetails`). The frame view's "About this frame" shows them, so the archive's author and copyright appear beside the roll's details. Its own endpoint rather than part of `GET /api/rolls/{rollId}`, whose roll shape is shared by every roll and frame response.
