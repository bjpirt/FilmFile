# FF-214 A frame's writes in one place

**Status:** to do · **Group:** 16. Internal improvements

## Why

`apps/web/src/frames/use-save-frame.ts` is 493 lines: one hook holding every write the frame view makes, each with its own `If-Match`, 409 check, optimistic update and refresh, interleaved with the queue that keeps them in order. After FF-212 it reads the roll through `useRoll`; its writes should follow the same pattern as the roll page's.

## What

The frame view's writes move to `frames/frame-changes.ts`, one function each, as `rolls/roll-changes.ts` does for the roll page (FF-212). `useSaveFrame` keeps what's about the view: the queue, the optimistic updates and what it shows while a save is under way. Nothing a person sees changes. _(Recommendation R7 of the architecture review, for frames. The review advises doing this when feature work next touches the frame view, not up front.)_

## Acceptance criteria

- [ ] `apps/web/src/frames/frame-changes.ts` has one function for each write `useSaveFrame` makes: save a frame's changes, add a version, delete a version, delete the frame, turn a version, change a version, and choose the version shown.
- [ ] Each takes the client, the query client, the roll as read and the change, and returns `'saved' | 'changed-elsewhere' | 'failed'` (with what the server gave back, where the view needs it). Each sends `If-Match`, turns a 409 into `'changed-elsewhere'`, and refreshes what it refreshes now, with the comment saying why.
- [ ] `useSaveFrame` calls them, keeping its queue (`queued`) and optimistic updates (`showTurn`, `showChoice`), and is about half its length.
- [ ] `frame-details.tsx`'s details query (`['rolls', rollId, 'frames', frameId, 'details']`) has its key defined once, beside `rollKey` in `rolls/use-roll.ts` or in a `frames/use-frame-details.ts`, and `use-save-frame.ts`'s refresh of it uses that key.
- [ ] `frame-view.test.tsx`, the other web tests and the Playwright journeys pass unchanged.
- [ ] Each new function has a test for `'saved'`, `'changed-elsewhere'` and `'failed'`.

## Not in this task

- Splitting `frame-view.tsx` (803 lines).
- Changing the order or the optimistic behaviour of saves.
