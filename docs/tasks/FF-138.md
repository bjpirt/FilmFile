# FF-138 Updates

**Status:** later · **Group:** 10. Desktop app · **Was:** U86

## What

The app checks for a newer version and offers to install it (Electron's `autoUpdater`, from GitHub Releases). Needs signed builds (FF-137, FF-199). On Windows, `autoUpdater` needs a Squirrel installer in place of the zip (FF-197); on Linux it isn't supported, so the AppImage (FF-198) would only be told a newer release is out, with a link to it.
