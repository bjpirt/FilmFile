# U20 Raw scans as versions

**Status:** done · **Built in:** 6. Versions and scans

## What was built

"Add raw scan…" takes a Sony ARW raw or a TIFF as well as the web-native images (an ARW known by its name when the browser gives it no type), and the service checks every file by its signature (a TIFF's byte order and 42, as an ARW starts too), within the upload size limit; raws are never written to. A raw's size is its sensor's, read from its TIFF tables without decoding it, and its thumbnails come from the largest preview JPEG it carries; a plain TIFF's from the TIFF. Both are read by our own bounds-checked reader of TIFF tables, so `exiftool-vendored` wasn't needed. API: the versions endpoint takes `image/tiff`, `image/x-sony-arw` or `application/octet-stream` too. Not done: hiding a raw scan from contact sheets while the frame has a Scan, since the first version (the Scan) is the one shown (D46) until FF-135.
