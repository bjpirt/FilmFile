# S2.2 Typed client

**Status:** done · **Built in:** S2: Contracts and a basic UI

## What was built

Generate types from the spec with `openapi-typescript` and export an `openapi-fetch` client from the contracts package. A check in `pnpm verify` fails if the generated files are out of date. The spec is committed as `packages/contracts/openapi.json` and the types as `src/api-types.ts`, each checked by a file snapshot test; `pnpm generate` updates both. *(Was 0.3.2.)*
