# U17 Events across rolls

**Status:** done · **Built in:** Frames' own details and bulk editing

## What was built

A frame is in its own events if it has them (U15), otherwise its roll's. An event's page shows every frame in it, from any roll, in shot order, and leaves out a roll's frames put in other events; grouping by camera, lens or film stock uses a frame's own where it has one. A roll counts as in an event (on the Events page, in the browse panel and when grouping rolls by event) when it or any of its frames is, so it can sit under several events. Extends the "Bulk edit" journey.
