# FF-130 Sub-events

**Status:** later · **Group:** Later · **Was:** U19

## What

An event can have a parent event, set on the Events page when it's added or edited, e.g. "Jökulsárlón day" inside "Iceland 2026". Cards, list and details row show "Parent › Event"; the Events page and browse panel show events nested under their parents, and choosing a parent includes its sub-events' rolls, and a parent's event page includes its sub-events' frames. Group by Event groups by the roll's own event. An event can't be its own ancestor. Extends the "Organise by event" journey with a sub-event.
