# FF-111 The browse folder

**Status:** to do · **Group:** 3. Finding your way around the library · **Was:** U91

## Why

Browsing photos by roll and frame number in Finder, or opening one in another app, without knowing the library's layout.

## What

`Browse/` in the FilmFile folder holds a folder per roll, named by number and name, with a link to each version's file named by its frame number, kept in step as rolls change (D58).

## Acceptance criteria

- [ ] `Browse/2026/2026-014 Westfjords/` holds a link to each of the roll's versions, named `12A - 12340012.jpg`, `12A - DSC04412.ARW`.
- [ ] Renumbering frames, changing a roll's number or name, and adding or deleting versions or frames update the roll's browse folder within moments, never moving the originals.
- [ ] Opening a link opens the original; the originals are read-only (FF-109).
- [ ] Deleting a roll removes its browse folder.
- [ ] On starting, the service brings the whole browse folder up to date, removing anything that isn't a roll's.
- [ ] Where links can't be made, it says so and makes none (copies would be too big).

## Not in this task

- Browsing by event (could come later).

- Outside `Library/`, so not backed up or synced.
