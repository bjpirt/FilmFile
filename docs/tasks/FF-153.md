# FF-153 Roll number patterns

**Status:** later · **Group:** Later

## What

Roll numbers in a pattern of my own, set in Settings (kept in `settings.json`, D65) with a preview: `{year}`, a count with a width (`{n:3}`), and fixed text, e.g. `{year}-{n:3}` (as now), `{n:4}` (counting throughout) or `BP-{year}-{n:2}`. The count restarts each year when `{year}` is in the pattern. New rolls (FF-152) and Number rolls (FF-108) follow it; filed rolls keep theirs.
