# U58 Details edited in place

**Status:** done · **Built in:** 5. Describing frames

## What was built

Clicking the frame's camera, lens or event in "About this frame" turns it into a list of the archive's, with "The roll's: Nikon FE" first; choosing one saves it as the frame's own (or goes back to the roll's) with `If-Match`, and Esc or clicking away leaves it as it was. Values that can be changed this way are marked as such (a faint dashed underline); author, copyright and film stock (D45) aren't. Works from the keyboard.
