# S2.1 Contracts and OpenAPI

**Status:** done · **Built in:** 1. Foundations and the API slice

## What was built

Define the S1 routes with `@hono/zod-openapi`, with request and response schemas in `@filmfile/contracts`. Serve `/api/openapi.json` and the docs page at `/api/docs` (assets served locally, D2). Snapshot test of the spec. Path parameters are validated as ULIDs (422). Malformed JSON is a 400 with the usual `{ error }` body, since 422 is for valid JSON that breaks the rules. The docs page is Swagger UI from `swagger-ui-dist`, with its telemetry dependency's install script blocked. *(Was 0.2.6, 0.3.1, 0.3.3.)*
