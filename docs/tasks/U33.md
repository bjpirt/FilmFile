# U33 Rotate a frame

**Status:** done · **Built in:** 5. Describing frames

## What was built

In the frame view, "Rotate anticlockwise" and "Rotate clockwise" buttons turn the version shown a quarter turn each time. The turn is kept on the version (`transform.rotate`: 0, 90, 180 or 270), never by changing its file (D41), and saved with `If-Match`; the frame view, filmstrip and contact sheets all show it turned.
