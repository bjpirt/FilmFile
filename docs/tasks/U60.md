# U60 The first version is shown

**Status:** done · **Built in:** Multi-version frames

## What was built

A frame shows its first version everywhere (contact sheets, filmstrips, the frame view, events), not its newest (D46); "Set as default" goes from the frame view, and a `defaultVersion` already in a roll.json is still honoured. Choosing which version is shown is for later (FF-103).
