# FF-174 Hide a frame

**Status:** done · **Built in:** 5. Describing frames

## Why

Some frames aren't worth looking at every time: a blank leader, a double exposure, a shot that went wrong. Deleting them loses them, but they shouldn't crowd the roll, or be found in a site, either.

## What

A frame can be hidden: it stays in the archive and in its roll's `roll.json`, but it's left out of every list of frames, and of every site and export, until it's unhidden. Pointing at a thumbnail shows an open eye at its top right that hides the frame; a hidden frame, where it's shown, has a closed eye that unhides it. The frame view has a "Hide frame" button and the key H, and the Set menu has Hide and Unhide for the frames selected. A page can show its hidden frames, dimmed, with "Show hidden frames" (D99).

## Acceptance criteria

Hiding and showing:

- [x] Pointing at a thumbnail on a roll page or an event page shows an open eye at its top right (the stars of FF-149 stay at its top left), named "Hide frame 3"; clicking it hides the frame without opening it. On a screen with no hover, such as a phone, it's always visible.
- [x] The frame leaves the page at once and is saved in the background, like a rating (FF-149); if it can't be saved, it comes back with the message "Couldn't hide frame 3." in the usual place.
- [x] The eye buttons are skipped by Tab (`tabindex="-1"`), as the stars are, but reachable by a screen reader; the frame view's key and Bulk edit are the keyboard ways.
- [x] "Show hidden frames" (and then "Hide hidden frames") in a roll page's Actions menu, and in an event page's, shows hidden frames dimmed, each with a closed eye at its top right named "Unhide frame 3", always visible; clicking it unhides the frame. The choice is kept in the page's address (`?hidden=show`), so reload, Back and the frame view opened from it keep it, and it isn't remembered once you go to another roll or event.
- [x] The frame view has a button "Hide frame" beside "Delete frame" and the key H, which hides the frame shown and moves on to the next frame that isn't hidden (or back to the roll or event, if none), as deleting does; ignored while typing in a field and with Ctrl, Cmd or Alt held.
- [x] A hidden frame opened directly, or from a page showing hidden frames, says "Hidden" beside its number, the button reads "Unhide frame" (and H unhides it), and stepping skips hidden frames unless the page it came from shows them (`?hidden=show`).
- [x] In Bulk edit, the Set menu has "Hide" and "Unhide" beside "Mark to scan" and "Unmark", saying "3 frames hidden." and "3 frames unhidden."
- [x] Select all and shift-click choose only the frames shown.

Where hidden frames are left out:

- [x] A roll page says how many it has, "36 frames (3 hidden)", counts and lists only the frames shown, and, with every frame hidden, says "3 hidden" and "Show hidden frames" in the place of the sheet; the roll card and list count only the frames shown, and the card's first three scans skip hidden frames.
- [x] Event pages, the rolls page's "Group by Event" and the browse panel's counts leave hidden frames out, and the "to scan" count ignores them.
- [ ] A site or export never includes a hidden frame, however its selection finds it (FF-119, FF-120, FF-165, FF-167, FF-177); to share one, unhide it first. *(Nothing makes sites or exports yet: each of those tasks must leave hidden frames out, as it's built.)*
- [x] Hiding changes nothing else: a hidden frame keeps its frame number, takes part in renumbering and goes with its roll when it's deleted, and its files, versions and details are untouched.

Data and API:

- [x] A hidden frame has `"hidden": true` in `roll.json`, stored only when it's hidden, so an unhidden frame and every existing file say nothing, and saving keeps the file byte-for-byte.
- [x] The service's frame has `hidden` (true or false), the update-frame request takes it, and so does the bulk details request, in one save with the roll's `If-Match`.

## Not in this task

- A way to list every hidden frame across rolls (a "Hidden" page), or a hidden count in the main navigation.
- Undo after hiding; unhiding is by the eye, "Unhide frame" or the Set menu.
- Hiding a version, or hiding a frame from one site or export only (FF-119's "frames pinned or hidden by hand", FF-163).

## Notes

- D99: hidden is a frame's own state, stored as `hidden: true` beside `toScan`, left out of every list, site and export, with a per-page "Show hidden frames" in the address.
- The eye reuses FF-149's thumbnail overlay; "Show hidden frames" is in the address as `?hidden=show`, read where the rolls page's and the event page's address already are (`rolls-address.ts`, `events/event-frames.ts`).
- One place decides what's shown: a helper beside `eventsOfFrame` (`events/frame-events.ts`) filters a roll's frames, used by the roll page, event pages, the card and list, the grouping, the browse panel's counts and the frame view's stepping.
- Sites and exports read frames through the service, which leaves hidden frames out of a selection's results (FF-177's), so the rule is one piece of code on the backend.
- Tests: the use cases and API (hide, unhide, bulk, `If-Match`, the stable file), the helper, the roll page, event page and frame view (the eye, the key, stepping, `?hidden=show`, counts); a journey: hide a frame from a thumbnail and from the frame view, see the counts, show hidden frames and unhide it.

## What was built

`hidden` on the frame through every layer (`domain/rolls/roll.ts`, `roll-file.ts` writing `"hidden": true` only when set, the update-frame and bulk use cases, `contracts/rolls.ts`, regenerated OpenAPI). In the browser, `rolls/hidden-frames.ts` (`showingHidden`, `shownFrames`, `hiddenCount`) decides what's listed; `FrameMarks` has the eye (`eye-icon.tsx`), placed beside the bin on a roll's page, and `use-rate-frame.ts` hides and unhides from a thumbnail like rating. The roll page and event page count "(3 hidden)", have "Show hidden frames" in their Actions menus, and keep `?hidden=show` in the address (`eventQuery` on the event side); cards, the list, `eventsOfRoll` (Group by Event and the browse panel) and event cards leave hidden frames out. The frame view has "Hide frame" / "Unhide frame", H and a "Hidden" mark, and moves on after hiding; Bulk edit's Set menu has Hide and Unhide. Tests at each level, and the `hide-frames` journey.
