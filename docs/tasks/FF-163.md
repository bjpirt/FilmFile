# FF-163 Add selected frames to a site

**Status:** later · **Group:** 13. Sites

## What

While selecting frames on a roll's page or an event's page, the Set menu offers "Add to site…" and "Leave off site…": choose a site and the frames are pinned or hidden on it (FF-119's "Always include" and "Never include"), without opening the site's page.

## Acceptance criteria

Written when the task is planned into a group.
