# FF-205 Bring the architecture documents back in line

**Status:** done · **Built in:** 16. Internal improvements

## Why

Agents and people read `CLAUDE.md` and `docs/design.md` before every task, and they describe things that aren't built: a SQLite adapter that doesn't exist, and a port table missing six ports. Two documents describe the architecture, and they'll keep drifting apart.

## What

The documents say what's built and what's planned, and each has one job: `docs/design.md` section 13 holds the rules and the reasons; `docs/technical-architecture.md` holds what's built (every port and adapter, and a request's walk through the layers). Documents only; no code changes. _(Recommendation R4 of the architecture review.)_
