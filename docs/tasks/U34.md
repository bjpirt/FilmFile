# U34 Add a version

**Status:** done · **Built in:** 6. Versions and scans

## What was built

A "+" ("Add a version") picks an image file and adds it to the frame as another version, keeping its file name; a frame can have any number. On a frame with one version the "+" sits in the frame view's bar with rotate, delete and details; once it has more, it moves to the foot of the versions column (U61). Web-native images only for now: JPEG, PNG and WebP, checked by file signature, not extension, within the upload size limit, and served back with their own type. The first version stays the one shown (D46). API: the existing versions endpoint takes PNG and WebP as well as JPEG.
