# U55 One Actions menu

**Status:** done · **Built in:** 3. Rolls and the roll page

## What was built

The roll page's buttons (Edit details, Add scans, Select, Renumber…, Delete roll…) become one "Actions" button beside the roll number, opening a menu: Edit details, Add scans, Bulk edit, Renumber…, then Delete roll… set apart. It works from the keyboard (arrow keys, Enter, Esc) and closes when something is chosen or on a click outside. Asking "Delete this roll?" and renumbering take the menu's place as they take the buttons' now. Extends the "Catalogue a roll" and "Renumber a roll" journeys, whose steps change.
