# FF-245 Prepare a release from GitHub

**Status:** later · **Group:** 10. Desktop app

## What

What `pnpm release` does (FF-243), from Actions › "Prepare release" › "Run workflow", with a choice of patch, minor or major, so a release can be started without a checkout. A pull request opened with the workflow's own `GITHUB_TOKEN` doesn't start CI, which `main`'s ruleset needs before merging (FF-242), so it needs a GitHub App's token kept as a secret.
