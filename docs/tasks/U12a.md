# U12a Events

**Status:** done · **Built in:** 4. Metadata

## What was built

Events with a name (`events/<slug>.json`), chosen for a roll on the new roll page and in Edit details from a dropdown whose Add new… asks for the new event's name, as for equipment; a roll belongs to at most one event (D24). Shown in the roll's details row, on cards and as a List column; Group by Event, with "No event" last; an Events section in the browse panel with counts, filtering the rolls by event (`?event=<slug>`). An Events page, from the header's Events link, lists the events with how many rolls each has, each linking to its rolls. Adds the "Organise by event" journey.
