# FF-163 Exclude selected frames from a site or export

**Status:** dropped · **Group:** 13. Sites

## What

While selecting frames on a roll's page or an event's page, the Set menu offers "Exclude from site…" and "Exclude from export…": choose a site or export and the frames are excluded from it (FF-181), without opening its page. Adding frames the rules don't find has no way now there is no pinning (D103); decide it when this is planned.

## Acceptance criteria

Written when the task is planned into a group.

## Dropped

With no pinning (D103) a frame gets on a site only by its rules, and the × on a site's page (FF-181) excludes one, so this adds only a shortcut. Picking frames by hand from a roll page for a site would be a new task, needing a way to add frames the rules don't find.
