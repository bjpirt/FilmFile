# FF-102 A roll's frames grouped by event

**Status:** done · **Built in:** 5. Describing frames · **Was:** U71

## Why

A roll shot across a trip and a day out reads better split by what was being photographed.

## What

When a roll's frames are in more than one event (the roll's, and frames' own, U17, D50), its page shows them under a lighter label for each event: the event's name, linking to its page, with its frame count. A frame is in the event it has of its own, else its roll's.

## Acceptance criteria

- [x] A roll whose frames are in two or more events, counting "no event" as one, shows a label for each, with its frames under it in frame order. Each label is an `h2` styled as a lighter, muted line above the group (not as prominent as the roll's own title): the event's name and its frame count, e.g. "Iceland 2026 · 12".
- [x] The groups come in the order of their first frames, with frames in no event under "No event", last.
- [x] Each event's label links to its event's page; "No event" doesn't link.
- [x] A roll whose frames are all in one event, or in none, looks as it does now, with no labels.
- [x] Changing a frame's event (in bulk edit) regroups the sheet straight away, including a group appearing, disappearing or moving.
- [x] While renumbering, every frame shows in scan order, without groups.
- [x] Bulk edit works across the groups: Select all selects every frame, and shift-click selects a run in the order on screen, across labels.
- [x] Opening a frame from the sheet steps through the roll's frames in frame order (Previous, Next and the filmstrip), whatever grouping the sheet showed.
- [x] In the "Bulk edit" journey: after giving a run of frames another event, the roll page shows a label for each event with the right frames under it.

## What was built

`rolls/group-by-event.ts` (`groupFramesByEvent`) groups a roll's frames, in frame order, by the event each is in (`eventsOfFrame`), in the order of their first frames with frames in no event last. When there's more than one group (and not while renumbering), the roll page draws each as a section: an `h2` (`.event-group-title`, a lighter, muted line) with the event's name as a link to its page (or plain "No event") and "· 12", above its own list named "Frames in <event>". The sheet's order for selection is the flattened groups, so Select all and shift-click follow what's on screen; the frame view still steps in frame order. A roll in one event, or none, keeps the single "Contact sheet" list. The frames' list items moved into a `frameItem` function in `rolls/roll-page.tsx` so both layouts share them.

Tests: the grouping function, roll page tests (labels, order and counts, links, one event or none, a frame's own event over the roll's, regrouping after a bulk edit, renumbering, Select all and shift-click across labels), a frame view test that stepping follows frame order, and the "Bulk edit" journey extended.

## Not in this task

- Grouping by anything else on the roll page.
- Collapsing a group, or the frame view stepping in the sheet's grouped order (it keeps the roll's frame order).
- Grouping on the event page, which groups by roll, camera, lens or film stock (D33).

## Notes

- Needs FF-101 (D50), so each frame has one event: `eventsOfFrame` (`events/frame-events.ts`) gives it.
- The roll page's contact sheet is split into one list per group; each group's list is named for its event ("Frames in Iceland 2026"), and a roll with no grouping keeps its single "Contact sheet" list, so the journeys' `framesShown` still works there.
- The order of the sheet (grouped) and the order selection runs follow are the same list, so shift-click follows what's on screen; the frame view's neighbours come from `inFrameOrder` as now.
- Event names come from the events list the page already reads (`useEvents`).
- Tests: roll page tests for the labels, their order, the links, "No event" last, no labels with one event or none, regrouping after a bulk edit, renumbering, Select all, and shift-click across labels; a frame view test that stepping follows frame order; the "Bulk edit" journey extended.
