# U83 Choose the archive

**Status:** done · **Built in:** 10. Desktop app

## What was built

On first launch the app asks "Where's your FilmFile archive?" with the system's folder picker ("Use This Folder", which can make a new folder): an empty folder (hidden files aside) is set up as a new archive in the window, as in a browser, and a folder of other files is refused ("That folder isn't a FilmFile archive.") and asked for again (`choose-archive.ts`, `folder-kind.ts`). The choice is remembered in the app's per-computer `settings.json` in Electron's `userData` (D52, `desktop-settings.ts`, read with Zod, written in one step). An archive that has gone missing says where it was and offers Try Again, Choose Another… or Quit (`find-archive.ts`). File › "Open Archive…" (⌘O, `app-menu.ts`) opens another in a new window on a new service, closes the old ones and remembers it. `FILMFILE_ARCHIVE`, when set, still comes first, for development and the journeys. Journeys: first launch, refusing a folder of other files and remembering the choice; switching with Open Archive…; and an archive gone missing. They answer the system's dialogs through `test/e2e/support/desktop-dialogs.ts`, loaded into the app with `-r` as Playwright loads its own.
