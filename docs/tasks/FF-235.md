# FF-235 Publish a site into a folder of a shared domain

**Status:** later · **Group:** 13. Sites

## Why

Putting a site under a path of a domain that already serves other things, such as `photos.example.com/iceland/`, not only on a domain of its own.

## What

An optional "Folder" on a site's publish target: everything is uploaded, compared and removed under that folder only, and Unpublish removes only what's under it. _(Split from FF-201, which publishes to a whole bucket first.)_

## Acceptance criteria

Written when the task is planned into a group.
