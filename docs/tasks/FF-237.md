# FF-237 Enter the Cloudflare keys in FilmFile

**Status:** later · **Group:** 9. Settings and the FilmFile folder

## Why

Setting up publishing (and later sync) without editing `~/.aws/credentials` by hand.

## What

The Cloudflare section of Settings (FF-236) takes the token's Access Key ID and Secret Access Key, kept on this computer only, in the OS keychain (in the desktop app, through Electron's `safeStorage`), never in the FilmFile folder, never returned by the API, and shown only as set or not set. The `[filmfile]` profile of `~/.aws/credentials` still works when they aren't set.
