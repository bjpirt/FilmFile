# U59 A frame's own date shot

**Status:** done · **Built in:** 5. Describing frames

## What was built

A frame can have its own date and time shot, in place of its roll's (D47): clicking the date in "About this frame" opens day, month, year and time, saved as the frame's own on Enter or on leaving the fields, with Esc keeping what it was, and the reset icon goes back to the roll's. Kept in roll.json as the frame's `shot`, only when set; resolved like the other details, with where it came from. An event's page puts frames in order by their own date where they have one.
