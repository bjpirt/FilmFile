# FF-107 Mark a roll as filed

**Status:** to do · **Group:** 2. Roll numbers · **Was:** U92

## Why

Once a roll's negatives are in the physical archive with its number on the sleeve, the catalogue must never move that number, or the shelf and the catalogue disagree.

## What

"Mark as filed" in a roll's Actions menu fixes its number: it shows as filed, its number can't be changed by hand or by Number rolls (FF-108), and, as its number no longer changes, its folder (`rolls/YYYY/YYYY-NNN-<ID>/`, D66) is never renamed again (D68).

## Acceptance criteria

- [ ] "Mark as filed" in the Actions menu marks the roll as filed; a small mark shows beside its number on its page, and on its card and row on the rolls page, named "Filed".
- [ ] Filing changes nothing on disk but `roll.json`: the folder keeps its name.
- [ ] A filed roll's number can't be changed (FF-106) or renumbered (FF-108), and the API refuses both (the status is settled when this is refined).
- [ ] On a filed roll, Edit details shows the number but not as a field, with "Filed: unmark it to change the number."
- [ ] "Unmark as filed…" asks first ("Only unmark it if its negatives aren't filed under this number.")
- [ ] A roll filed or unfiled elsewhere since the page loaded (409) says so and changes nothing.
- [ ] The rolls page can show only rolls not yet filed, from the browse panel, to see what's left to number and file.

## Not in this task

- Where a roll is filed (box, binder, page): could come later.

## Notes

- Decisions D66 (folder names) and D68 (filed numbers never change).
- roll.json: `filed: true`, only when set. API: `PATCH /api/rolls/{rollId}` takes `filed`.
