# FF-153 Roll number patterns

**Status:** later · **Group:** Later

## What

Roll numbers in a pattern of my own, set in Settings (kept in `settings.json`, D65) with a preview: `{year}`, a count with a minimum width (`{n:3}`), and fixed text, e.g. `{year}-{n:3}` (as now), `{n:4}` (counting throughout) or `BP-{year}-{n:2}`. The count restarts each year when `{year}` is in the pattern. A width is a minimum: automatically assigned numbers are zero-padded to it, but can grow beyond it (for example `2026-1000`). Manually entered valid numbers keep their spelling. Suffixes with the same numeric value are equivalent for uniqueness and sort numerically (`2026-1` and `2026-001` are the same number). This replaces the fixed-width suffix in D7. New rolls (FF-152) and Number rolls (FF-108) follow the chosen pattern; filed rolls keep theirs.
