# S1.5 Upload a lab scan

**Status:** done · **Built in:** S1: API slice — rolls and scans

## What was built

`POST /api/rolls/{rollId}/frames/{frameId}/versions?file=12340014.jpg` with the image as the raw body writes it unchanged to the version's own folder, `frames/<frame>/<version>/` (D17), and appends a version with its ULID, SHA-256, size, width and height (read with sharp). A second upload of the same bytes returns 409. Tests generate a small JPEG with sharp.
