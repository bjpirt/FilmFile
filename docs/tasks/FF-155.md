# FF-155 Frame and version folders named by number and kind

**Status:** to do · **Group:** 2. Finding your way around the library

## Why

In Finder, a roll's frames and their versions are a list of IDs (`Q2P7RM4K/8F3WXB1C/`). Naming them by frame number and version kind, with the ID after, makes the library readable as it is: `12A-K0D9TZ6E/raw-scan-V5M2QH8A/DSC04412.ARW`.

## What

A frame's folder is `<frame number>-<ID>` and a version's `<kind>-<ID>` (the last 8 characters of their ULIDs), renamed when the frame is renumbered or the version's kind changes (D69). `roll.json` records each version's path, updated in the same save as each rename. *(Replaces D17's and D58's folders named by ID alone, and CLAUDE.md's "renumbering never moves files".)*

## Acceptance criteria

- [ ] A new frame's folder is `frames/<frame number>-<ID>/`, e.g. `frames/12A-K0D9TZ6E/`; a frame with no number is `unnumbered-<ID>`.
- [ ] A frame number is cleaned for the folder's name: letters, digits and hyphens are kept and anything else becomes `_` (`14-15` stays `14-15`; `12/13` becomes `12_13`), and a leading dot or hyphen doesn't hide or break the name.
- [ ] A new version's folder is `<kind>-<ID>/`: `scan-…`, `raw-scan-…` or `final-…`, with its file inside under its original name, as now.
- [ ] Renumbering a frame (by hand, or renumbering the roll) renames its folder, and changing a version's kind renames the version's folder; `roll.json`'s paths are updated in the same save, and the files themselves are never renamed or changed.
- [ ] Renumbering a whole roll, where frames swap numbers, renames every frame's folder without clashes, as the IDs keep names apart.
- [ ] Frames and versions made before this task keep their folders, named by ID alone, until they're renumbered or their kind changes, and then are renamed the same way.
- [ ] Thumbnails, originals, deleting and everything the UI shows work as before; no response gives a path.

## Not in this task

- Recovering files whose rename was interrupted (FF-156).
- Renaming the files themselves, which keep their original names.
