# U38 Delete selected frames

**Status:** done · **Built in:** 5. Describing frames

## What was built

*(Was 1c.3, "Bulk edit and delete". Selecting frames and setting their event, camera, film stock or lens: U14, U16; location: FF-133, later; tags: FF-132, later.)* With frames selected, "Delete…" in the bar asks "Delete these 3 frames?" in place of its buttons, so the frames don't move; Delete takes them out of the roll in one save with `If-Match` and moves each into `deleted/`, as for one frame (U23), leaving nothing selected. Esc or Cancel keeps them. `DELETE /api/rolls/{rollId}/frames?frameIds=…` (`DeleteFrames`); nothing is deleted if any frame isn't in the roll.
