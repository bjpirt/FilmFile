# FF-110 A contents file in each roll's folder

**Status:** to do · **Group:** 3. Finding your way around the library · **Was:** U90

## Why

Dipping into the library in Finder, I can see which folder is which frame without opening roll.json.

## What

Each roll's folder has a `contents.txt`, rewritten whenever the roll is saved, listing its frames by number with their folders and files; and `Library/README.txt` says what each part of the library is.

## Acceptance criteria

- [ ] Each roll's folder has a `contents.txt`, starting with the roll's number, name and date shot.
- [ ] It lists every frame in frame order, one line each, with its folder and its versions' files and kinds: `12A  frames/Q2P7RM4K/  12340012.jpg (Scan), DSC04412.ARW (Raw scan)`.
- [ ] It's rewritten whenever the roll is saved, so renumbering, adding or deleting a version shows in it.
- [ ] A roll saved with nothing changed leaves `contents.txt` byte for byte the same.
- [ ] `Library/README.txt` says what the library's folders are and that roll.json, not folder names, says which frame is which.
- [ ] Both say they're written by FilmFile and that changes to them are overwritten.

## Not in this task

- Changing folder names (D17, D58).

## Notes

- Written by the filesystem adapter with each save of roll.json; never read back.
