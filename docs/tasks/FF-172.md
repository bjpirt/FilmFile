# FF-172 Back to the rolls you were looking at

**Status:** done · **Built in:** 3. Rolls and the roll page

## Why

Filtering the rolls (to a year, say), opening one and going back shouldn't lose the filter.

## What

The rolls page's filter, grouping, sort and view are remembered for the browser tab, and the links back to the rolls (the breadcrumb on a roll, a frame, New roll and Bulk import, the "Rolls" link in the main navigation, and the page shown after deleting a roll) go to them. The breadcrumb reads "Rolls", not "All rolls", since it may now lead to a filtered list.

## Acceptance criteria

- [x] After filtering the rolls (year, camera, film stock or lens), opening a roll and choosing the "Rolls" breadcrumb shows the same filter, with its heading (for example "Rolls from 2026").
- [x] The same goes from a frame's page, New roll and Bulk import, and for the "Rolls" link in the main navigation.
- [x] Group by, Sort by and the Grid | List choice are brought back the same way.
- [x] Deleting a roll lands on the rolls as they were filtered.
- [x] A new tab, or a tab where the rolls haven't been shown, starts unfiltered.
- [x] The breadcrumbs on the roll, frame, New roll and Bulk import pages, and the matching button after an import, read "Rolls" rather than "All rolls".
- [x] Reload, back, forward and bookmarks still keep the filter through the address, as before (D23).
- [x] When the browser won't store anything, the links go to the unfiltered rolls.

## Not in this task

- Keeping the filter across restarts or for other tabs; it's per tab (`sessionStorage`).
- The "FilmFile" name in the header, which still goes to the unfiltered rolls.

## Notes

- `rememberAddress` and `rollsLink` in `rolls/rolls-address.ts`; the rolls page records its address whenever it changes.
- Page test: filter, open a roll, "Rolls" breadcrumb; journey: the same in `test/e2e/roll.e2e.ts`.

## What was built

`rememberAddress` and `rollsLink` (`rolls/rolls-address.ts`) keep the rolls page's address, filter, grouping, sort and view, in `sessionStorage`, and fall back to `/` when storage is missing or empty. The rolls page records its address whenever it changes. The breadcrumbs on the roll, frame, New roll and Bulk import pages, the import summary's button, the Rolls link in the main navigation, "Cancel" on New roll and the page shown after deleting a roll use `rollsLink()`. Tests: the helpers (`rolls-address.test.ts`), going back from a roll and through the navigation (`app.test.tsx`), and a step added to the `find-rolls` journey.
