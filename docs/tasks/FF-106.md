# FF-106 Change a roll's number

**Status:** to do · **Group:** 3. Roll numbers · **Was:** U25

## Why

A roll number mistyped, or that should follow another, can be put right.

## What

"Change roll number…" in a roll's Actions menu asks for the new number and moves the roll's folder; the roll keeps its ID, so links to it still work (D10). *(From 1.3.15, 1.4.3 and 1c.2.)*

## Acceptance criteria

- [ ] "Change roll number…" in the Actions menu asks for the new number, filled in with the current one.
- [ ] A number that isn't `YYYY-NNN`, or that's taken, is refused, saying which.
- [ ] Changing it moves the roll's folder to its new number's place (`rolls/2026/2026-009/`), and the roll page, its address and the rolls list show the new number.
- [ ] Links to the roll and its frames keep working, as they use its ID.
- [ ] A change refused because the roll changed (409) says so and changes nothing.

## Not in this task

- Numbering many rolls at once (FF-108).
- Locked rolls (FF-107).

## Notes

- API: `POST /api/rolls/{rollId}/rename` with `If-Match`.
- The repository's `rename` already exists from the first plan; check it moves the folder in one step.
