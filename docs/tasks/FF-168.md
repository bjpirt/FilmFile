# FF-168 Select frames on an event's page

**Status:** to do · **Group:** 12. Exports

## Why

An event's frames from every roll, as files in one go, picked by clicking them.

## What

An event's page gets a selection mode like a roll's: a "Select" button, checkboxes on the frames, "Select all" and "Clear", and an "Export…" button that opens FF-167's dialog. Nothing else can be done to the selection (setting details across rolls isn't part of this).

## Acceptance criteria

- [ ] An event's page has a "Select" button; in selection mode each frame has a checkbox in place of opening it, the bar says how many are selected ("12 frames selected"), and has "Select all", "Clear", "Export…" and "Done", and Esc leaves selection mode.
- [ ] Clicking a frame's picture or its checkbox selects it; shift-click selects a run in the order shown (across groups, as the page groups them).
- [ ] "Export…" opens "Export 12 frames", as on a roll's page, and downloads one zip named for the event (`Iceland 2026.zip`) with the frames' layout and names as chosen; with "A folder per roll" the folders are the frames' rolls.
- [ ] Frames from different rolls are in the zip together, each made from its own roll's version shown.

## Not in this task

- Setting a camera, lens, event, or a scan mark on the selected frames, or deleting them, from the event page.

## Notes

- Reuses the roll page's selection (`rolls/selection.ts`) and FF-167's dialog and request.
- Tests: the selection mode on the event page and an export of frames from two rolls read back from the zip.
