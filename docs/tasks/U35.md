# U35 Meta resolver

**Status:** done · **Built in:** 5. Describing frames

## What was built

*(Was 1.1.6. For camera, film stock, lens and events: U15.)* `resolveDetails` (`domain/details/`) resolves a frame's inherited details from its layers, archive → roll → frame: author, copyright, camera, film stock, lens and events. A scalar replaces the one inherited, a list replaces it or changes it with `{ add, remove }`, and `null` clears either; each value records the layer and ID that set it. `resolveEquipment` turns the camera, film stock and lens slugs into their records, reporting a slug with no record rather than failing. Map merging, layers from events and overriding an equipment record's fields wait until a detail needs them.
