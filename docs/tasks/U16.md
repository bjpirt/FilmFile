# U16 Assign to selected frames

**Status:** done · **Built in:** Frames' own details and bulk editing

## What was built

With frames selected (U14), the bar offers "Set event…", "Set camera…", "Set film stock…" and "Set lens…": each opens a choice of the archive's, or "The roll's" to clear the frames' own, and saves it for every selected frame in one save with `If-Match` (U37), so a roll changed elsewhere isn't overwritten; "Camera set on 3 frames." says it's done, and the frames are marked as having their own (U15). Deleting the selected frames is in U38. Adds the "Bulk edit" journey.
