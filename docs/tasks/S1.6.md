# S1.6 Thumbnails and originals

**Status:** done · **Built in:** S1: API slice — rolls and scans

## What was built

`GET /api/rolls/{rollId}/frames/{frameId}/versions/{versionId}/thumbnail?size=small|large` returns a 400 px or 2048 px WebP made with sharp and cached in the cache directory by content hash; `GET …/versions/{versionId}/file` returns the original.
