# FF-137 A signed and notarised Mac app

**Status:** later · **Group:** Later · **Was:** U85

## What

Signed with a Developer ID and notarised by Apple (`@electron/packager`'s `osxSign` and `osxNotarize`), so it opens without warnings on any Mac. Needs an Apple Developer Program membership, kept out of the repository (CI secrets).
